# Test Kitchen — October 19, 2026

Adjust recipe is gone. Its sheet on top of a recipe edited a hidden draft and ended in a Save / Save as new choice, so it was hard to switch formulas, hard to tell which one was being edited, and saving felt destructive. Test Kitchen (`/kitchen`) replaces it as a section beside Recipes and Learn, following the approved proposal (variant A, “Notebook”).

- **Recipes render as written.** The calculator plugin still projects its authored default into the recipe (dough weights, bound step text, sourdough process steps). The recipe page has no summary, sheet or saved-formula choice; one line links to Test Kitchen and, for members, to their versions of that recipe. Old `?config=` links redirect to the unsaved calculator.
- **Anyone can use the calculator** at `/kitchen/<recipe>`. Unsaved work stays in that browser. “Sign in to save” returns with `?save=1` and opens the name step.
- **Saved formulas** have their own page, named in the heading, with a “Changed from the recipe” strip and Reset. Edits autosave with the revision they started from, so another tab's newer save is never overwritten (409). History keeps the last 100 versions, groups edits within two minutes and never folds edits into the created entry. Restore adds a new version and can be undone. Duplicate asks for the name first; names are unique per member regardless of case. Delete is soft for 30 days with Undo and Recently deleted.
- **Bake sheet** is where a saved formula opens: library cards, recipe-page links and Save all land on it, and Edit formula leads to the editor. It renders the recipe with the formula's numbers, Print and Cooking view. Today's batch (`?count=`) never edits the formula.
- **Data:** `kitchen-formulas` and `kitchen-revisions` (migration `20261019_114245_kitchen_formulas`, additive, `onlineCompatible`). Their own capability, no REST/admin, routes under `/api/public/account/kitchen/formulas`. Kitchen table names stay outside the content-sync allowlist. Account deletion removes both. `member-workbenches` is retired, kept declared and not migrated (owner's choice).
- **Code:** `packages/l7/kitchen` (pages, shared controls, client contract, in-memory fixture); the app's dough editor and results in `apps/eatyeet/src/workbenches`; the recipe registry contract in `l7/recipes` is now projection-only. Shared formula-state validation moved to `l2/recipe-domain/formula-state`. `NumberField` gained the `underline` surface.
- **Not included:** bake logging, ratings or comments on formulas, and public formulas (deferred by the owner); a “New” nav tag.
